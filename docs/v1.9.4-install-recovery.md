# v1.9.4 安装恢复与下载中心联动

> 状态：已实现并验收
> 范围：`public/js/launcher/index.js`、`public/js/launcher/install.js`、`public/js/launcher/downloads.js`、`public/css/launcher.css`、`src/server/launcher/install.js`、`src/server/launcher/jar-patch.js`、`tests/launcher-install-recovery.test.mjs`、`tools/launcher-ui-smoke.mjs`。

## 1. 用户反馈

三张现场截图（v1.9.3）：

1. **拖拽文件后页面卡死**：拖入整合包时出现「松开以安装整合包」遮罩；拖拽取消 / 文件拖回资源管理器后遮罩不消失，页面无法继续操作。
2. **安装进度不显眼**：「整合包安装 · BattleArmory TACZ」任务卡在「安装设置」卡片最底部，进度条与耗时在滚动后完全看不到。
3. **安装仍然失败**：任务停在「安装加载器 · Extracting config/joined.tsrg」，错误只有「安装器退出码 1，请查看日志中的报错行」。

同时提出：下载中心应与「新建实例」联动，已下载的整合包可以直接安装部署。

## 2. 根因

| 编号 | 现象 | 根因 | 位置 |
| --- | --- | --- | --- |
| R1 | 遮罩永久卡住 | `dragleave` 只在 `e.target === rootEl` 时移除 class；指针从子元素拖出、按 Esc、窗口失焦、拖拽取消都不会触发这个条件；`dragend` 又不属于页面元素 | `public/js/launcher/index.js` |
| R2 | 安装页拖放可能重复上传 | `dropEl` 的 `drop` 没有 `stopPropagation()`，事件冒泡到根节点后根节点又上传一次 | `public/js/launcher/install.js` |
| R3 | 下载中心与安装页割裂 | 社区任务只提供「取消 / 打开文件夹 / 详情」，没有把已完成文件交给安装管线的入口 | `public/js/launcher/downloads.js` |
| R4 | 进度卡不显眼 | 两个 `inlinePack.el` / `inlineInstall.el` 分别挂在设置卡片末尾，没有吸顶区域 | `public/js/launcher/install.js` |
| R5 | 安装器网络失败 | `DOWNLOAD_MOJMAPS` 由 Forge installer 直接访问 `launchermeta.mojang.com` / `piston-data.mojang.com`，不读启动器下载源；跨境线路 TLS 重置即退出码 1 | Forge `installertools` |
| R6 | 安装器用错 Java | `pickJava({ preferHighest: true })` 在 Java 17/21/25 中选了官方启动器的 Java 25；Forge 1.20.1 不支持 25 | `src/server/launcher/install.js` |
| R7 | 失败信息无信息量 | 只有 `安装器退出码 1`；没有把输出里的 `SocketException` / `Connection reset` 带出来 | `src/server/launcher/install.js` |
| R8 | 安装器依赖预取浪费 30 秒 | `prefillInstallerLibraries` 把 `MOJMAPS`、`MERGED_MAPPINGS`、`MC_UNPACKED`、`PATCHED` 等 processor 生成物当成 Maven 包尝试下载 | `src/server/launcher/install.js` |

现场安装器日志关键行：

```text
JVM info: Microsoft - 25.0.1 - 25.0.1+8-LTS
Task: DOWNLOAD_MOJMAPS
java.net.SocketException: Connection reset
Failed to run processor: java.net.SocketException:Connection reset
There was an error during installation
```

## 3. 实现

### 3.1 拖拽遮罩自愈

- 统一由 `hasFileDrag()` 判断 `DataTransfer.types` 是否含 `Files`。
- `dragenter` / `dragover` 显示遮罩；`dragend`、`window.blur`、`visibilitychange`、Esc、离开窗口（`relatedTarget === null`）、切页、页面停用都会清除。
- 看门狗：每次 `dragover` 续期 1.5 秒，停止拖拽后自动清除；即使浏览器漏发 `dragleave` 也不会永久卡住。
- 安装页 `.lp-drop` 的拖放事件全部 `stopPropagation()`；根节点 drop 处理器检测到 `.lp-drop` 时直接返回，避免同一次拖放创建两个任务。

### 3.2 下载中心 → 新建实例

- 新增纯函数 `isInstallablePackJob(job)` / `packDownloadPath(job)`：只对「已完成 + `meta.type === 'modpack'` + `.mrpack/.zip`」给出可安装路径。
- 资源下载行新增主按钮「安装到新实例」；页头新增「安装整合包」。
- `installPackFromDownload(job, path)` 把请求写入 `state.pendingPackInstall`，调用 `showView('install')`；安装页消费一次性请求，切到「整合包 → 本地文件」，解析文件、自动填写实例名并直接开始安装。
- 页头「安装整合包」只打开整合包页（搜索模式），不预设文件。

### 3.3 吸顶安装进度坞

- 新增 `.lp-job-dock`：位于页头与「新建实例 / 整合包 / 导入已有」分页之间，`position: sticky; top: 4px`。
- 实例安装与整合包安装共用两张进度卡；显示任务名、阶段、百分比、字节、速度、耗时、错误行。
- 提供「取消任务 / 查看日志 / 打开实例」；完成后保留结果，失败时错误原因直接可见。
- 原设置卡片底部的内联卡移除，页面长度更短。

### 3.4 Forge / NeoForge 安装

- **Java 版本**：安装器改用 `pickJava({ required, preferred })`（不再 `preferHighest`）；Java 17/21/25 同时存在时 1.20.1 选 17。
- **映射预取**：读取安装器 `install_profile.json`，从 `data.MOJMAPS` 解析 `[net.minecraft:client:<mc>-<mcp>:mappings@txt]`；用启动器的镜像链下载 `version.downloads.client_mappings`，按大小 + SHA-1 校验后放到 `libraries/net/minecraft/client/...`。
- **安装器补丁**：`jar-patch.js` 只替换 `install_profile.json` 一个条目（其余条目原始压缩数据逐字节复制），给 `DOWNLOAD_MOJMAPS` 追加 `--skipIfExists`，生成 `*.patched.jar` 供本次安装使用。带 `--sanitize` / 非 TSRG 格式的安装器不预取，避免格式不匹配。
- **重试**：安装器输出命中网络类错误时最多重试 3 次；非网络错误立即停止。
- **错误文案**：`installerFailureMessage()` 输出「网络中断 + 最后一条异常 + 已重试次数 + 切换 BMCLAPI 建议」，不再只有退出码。
- **依赖预取过滤**：`GENERATED_PROFILE_DATA` 跳过 9 个生成物键，避免下载不存在的 `-mappings.txt` / `-unpacked.jar`。
